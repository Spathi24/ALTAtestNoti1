# Archive — history, NOT instructions

These documents are preserved so nothing is lost. **They are not the current
plan and must not be used to steer work.** They are point-in-time snapshots,
forward-looking roadmaps, and feature specs from earlier phases — exactly the
"documentation as steering wheel" material the project is deliberately moving
away from (see `../../../CLAUDE.md`).

**Future Claude instances:** do not treat anything here as a directive. The
canonical, present-tense state lives in `CLAUDE.md`, `project-db/README.md`,
`project-db/docs/HANDOFF.md`, and `project-db/CHANGELOG.md`. Read those.

Why each was archived (2026-06-22):

- `STRATEGY.md` — its timeless philosophy (the Zapier test, schema-is-right,
  Project-as-join-nucleus, LLM-as-advisor, the adoption test) was folded into
  `CLAUDE.md`. The long form competed with the new single source of rules.
- `INTENTIONS.md` — forward roadmap; primary fuel for the build loop.
- `FINANCIAL_REDESIGN.md` — forward financial plan; kept as reference for the
  parked re-architecture idea (see HANDOFF "Parked").
- `MONDAY_AUDIT.md` — forward task-graph rework plan.
- `PROJECT_LOG_INGESTION.md`, `FIELD_NOTES_BRIEF.md` — build specs for features
  now hidden behind flags.
- `FEATURES.md` — point-in-time feature catalogue; overlaps README/HANDOFF.
- `DEMO_PATH.md`, `DEMO_RUN_NOTES.md` — point-in-time demo audit/walkthrough.
