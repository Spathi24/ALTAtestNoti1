# ALTA / project_db — Documentation Map

This project accumulated many planning docs (each session tended to add a new
synthesis rather than reconcile the old ones). This index is the **single map**:
what to read, in what order, and which docs are live vs. historical. Read this
first if you are a fresh instance.

**Current state (2026-06-09):** on `main`, **806 tests passing**. The "brain" is
largely built — financial reconciliation, the deterministic attention briefing,
RAG over contracts, hybrid search, one-command refresh. Per every strategic doc,
the next bottleneck is **adoption, not more features** (STRATEGY §9 / rule N8).
**Budget reality:** Anthropic credits are at $0; OpenAI ~$4. A `FallbackProvider`
(Anthropic → OpenAI) keeps everything working; develop on mocks, treat any live
LLM run as a deliberate, budgeted action (now OpenAI cents).

## Read order (fresh instance)

1. **[../../CLAUDE.md](../../CLAUDE.md)** — the hard working rules (edit `main`,
   no worktrees; push after meaningful changes; keep the suite green; ASCII-only
   in CLI output). Read before touching code.
2. **[EVALUATION.md](EVALUATION.md)** — the honest current-state assessment +
   the standing **ALWAYS/NEVER rules (A1–A9, N1–N8)**. The single most useful
   doc. The owner clarifications at the top win where they conflict with the body.
3. **[HANDOFF.md](HANDOFF.md)** — the live engineering context: invariants, the
   financial layer, RAG, the briefing, worked-through problems, footguns, the
   API-budget reality, CLI/route maps.
4. **[FEATURES.md](FEATURES.md)** — plain-language "what does it do today" for a
   non-technical reader.
5. **[STRATEGY.md](STRATEGY.md)** — the durable mission ("contractor operations
   brain, not a sync tool") + the 10 operating principles.
6. **[INTENTIONS.md](INTENTIONS.md)** — the money-saving roadmap-to-build
   (commitments/Money-at-Risk, value-caught tally, usability wins, the
   acquisition/lead-gen north star).
7. **[../CHANGELOG.md](../CHANGELOG.md)** — day-by-day log, newest on top.
